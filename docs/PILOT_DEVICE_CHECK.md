## Minimum Requirements (DO NOT test below these thresholds)

| Requirement | Minimum Value |
|---|---|
| Android version | 9.0 (Pie) or higher |
| RAM | 2 GB |
| Browser | Chrome 105+ or Firefox 106+ |
| Available storage | 150 MB free (app + DB cache) |
| Microphone | Built-in or wired headset (no Bluetooth for first pilot) |
| Battery at session start | >= 40% |

## Pre-Session Device Verification Checklist

For every device, verify the following before each session:

```
[ ] Browser version confirmed at or above minimum
[ ] Available storage confirmed >= 150 MB
[ ] Battery confirmed >= 40%
[ ] Microphone permission granted to browser
[ ] PWA installed (Add to Home Screen)
[ ] App opened in PWA / standalone mode
[ ] Translations load (offline DB visible)
[ ] Network toggled OFF before pilot begins (offline test)
[ ] Screen auto-lock set to >= 5 minutes during session
[ ] Do Not Disturb / call forwarding confirmed ON
```
